## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `linux-support-team-portfolio`).
2. Upload `index.html`, `style.css`, `README.md`, and the complete `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site and open the URL shown in that section.
